# 👶 Ma Garderie

Application mobile développée dans le cadre de l'examen pratique . Elle permet de gérer et de consulter les menus quotidiens d'une garderie d'enfants.

---

## 🛠️ Technologies Utilisées
- **Framework :** Flutter (Dart)
- **Gestion de versions :** Git & GitHub
- **Outil de développement :** VS Code / Android Studio

---

## 📱 Fonctionnalités
- **Splash Screen :** Écran de démarrage animé avec une transition automatique après 3 secondes.
- **Page Principale :** Affichage d'une barre d'outils (AppBar) avec recherche et notifications, ainsi qu'un menu latéral (Drawer).
- **Liste des Menus :** Présentation dynamique sous forme de cartes (`ListView.builder`) des menus (petit-déjeuner, déjeuner, goûter, etc.).
- **Interactions :** Affichage de messages (`SnackBar`) lors des clics sur les boutons, le menu ou les éléments de la liste.
